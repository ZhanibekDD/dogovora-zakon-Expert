# ZakonExpert Bot

Telegram-бот для автоматического формирования юридических договоров ТОО «ZakonExpert» (БИН 260740044168, руководитель Кияшев Жанибек Даулетович).

## Договоры

Текущий production-шаблон формируется как **v4 light-trust**:

- 3 страницы A4: индивидуальные условия → правила работы → реквизиты и подписи;
- светлый корпоративный стиль без тяжёлых чёрных плашек;
- личные/иные банковские реквизиты не печатаются как реквизиты ТОО;
- оплата описывается через счёт или подтверждённую платёжную ссылку ZakonExpert;
- подпись и печать Исполнителя собираются в один прозрачный блок и вставляются в DOCX/PDF как единая композиция;
- текущая компактная геометрия блока: подпись 42 мм, печать 28 мм, общий блок 70×33 мм;
- печать слегка повёрнута и имеет уменьшенную непрозрачность, подпись лишь слегка пересекает линию — без эффекта большой вставленной картинки;
- ФИО подписанта остаётся отдельно читаемым под линией.

Основная бизнес-логика, генерация DOCX/PDF, электронное подписание и история версий сохранены.

Подробности конфигурации смотрите в `.env.example`.
